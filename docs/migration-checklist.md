# React 마이그레이션 회귀 체크리스트

바닐라 `app.js`에서 Vite + React 19 + TypeScript 구조로 전환한 뒤, 사용자에게 보이는 동작이 그대로인지 확인하는 목록이다. 자동 테스트가 덮지 못하는 항목만 남겼다.

준비:

```bash
npm run build && npm start   # http://localhost:4173
```

## 자동으로 검증되는 항목 (수동 확인 불필요)

| 항목 | 검증 위치 |
|------|-----------|
| 도메인 계산 (시간 경계, 리플렉션 규칙, 메모 상태) | `tests/domain/` 25건 |
| 상태 전이와 구독 통지 | `tests/store/` |
| 동기화 분기, AI 응답 검증 | `tests/sync/` |
| 시리얼 프로토콜 파싱, LED payload | `tests/device/` |
| 정적 서빙, 비공개 경로 차단, PWA 자산 | `tests/server.integration.test.mjs` |
| 배포 번들에 모든 자산 포함 | `tests/build/mockup.test.mjs` |
| 기록 중 카드 DOM 재생성 0건 | 헤드리스 Chrome 프로브 (Phase 4 SPEC 참조) |

## 수동 확인 항목

### 화면

- [ ] 홈 / 흐름 / 돌아보기 / 나 4개 탭이 하단 내비게이션으로 전환되고, 활성 탭에 알약 배경이 보인다
- [ ] `나` 탭 아이콘이 내가 고른 장난감이다
- [ ] 상단 브랜드를 누르면 오늘 탭으로 돌아온다
- [ ] 기록 탭에서 7일 ↔ 30일을 전환하면 히트맵 폭과 요약 수치가 함께 바뀐다
- [ ] 30일 지도는 오른쪽 끝(오늘)으로 스크롤된 상태로 열린다

### 기록

- [ ] 카드를 누르면 기록이 시작되고 상단 진행 바에 시계가 흐른다
- [ ] 같은 카드를 다시 누르면 종료되고 메모 다이얼로그가 열린다
- [ ] 다른 카드를 누르면 이전 기록이 종료되고 새 기록이 시작되며, 종료 알림이 뜬다
- [ ] 키보드 `1`~`4`가 같은 동작을 한다
- [ ] 활동 이름 입력 중에는 숫자 키가 기록을 시작하지 않는다
- [ ] 콘솔에서 `window.habitToy.pressButton(1)`을 호출하면 화면이 즉시 갱신된다

### 전체화면 기록

- [ ] 버튼을 누르면 활동 색의 전체화면이 열리고 목표 시간에서 시계가 **줄어든다** (목표 없는 활동은 올라간다)
- [ ] 0이 되면 "다 채웠어!" 발화 후 `+00:00:00`으로 초과 시간을 센다
- [ ] 초과 5분마다 "왜 안 끝났어?" 식으로 다시 말을 건다
- [ ] 홈 버튼에 `-25분 / 오늘 남음`처럼 남은 시간이 보이고 채우면 `채움 ✓`
- [ ] `접어두기` 또는 ESC로 접으면 기록은 계속되고 상단 바가 남는다
- [ ] 상단 바를 누르면 전체화면이 다시 열린다
- [ ] `끝`을 누르면 "끝~!" 소리와 함께 메모 다이얼로그로 넘어간다
- [ ] `나` 탭에서 `높은 톤` / `또렷한 톤`을 바꾸면 즉시 "시작!"이 들린다

### 메모

- [ ] 메모를 저장하면 기록 목록의 `메모 대기` 배지가 사라진다
- [ ] `메모 없이 완료`를 눌러도 기록 시간은 유지된다
- [ ] `나중에`를 누르면 오늘 탭의 메모 인박스에 남는다
- [ ] 메모 대기가 2개 이상이면 안내 문구가 개수 기준으로 바뀐다

### 한 줄 메모 보기

- [ ] 흐름 탭 최근 기록 헤더의 `한 줄 메모 보기`를 켜면 메모가 있는 기록 아래에 회색 작은 글씨로 메모가 보인다
- [ ] 새로 고쳐도 선택이 유지된다
- [ ] 메모가 있는 기록이 없으면 버튼이 비활성이다

### 편집과 복구

- [ ] 기록을 눌러 활동·날짜·시간·길이·메모를 수정할 수 있다
- [ ] 삭제한 기록이 설정 탭의 `최근 삭제한 기록`에 나타나고 복구된다
- [ ] 활동을 추가·이름 변경·보관·복원할 수 있다
- [ ] 같은 이름의 활동을 추가하면 오류 문구가 뜬다
- [ ] 나의 네 가지에 연결된 활동은 곧바로 보관되지 않고 안내가 뜬다

### 돌아보기

- [ ] 7일 ↔ 30일 전환 시 요약 4칸과 분포가 함께 바뀐다
- [ ] 근거 카드 3종이 나타나고, 기록이 부족하면 흐린 상태로 표시된다
- [ ] `OPENAI_API_KEY` 없이 AI 버튼을 누르면 안내 토스트만 뜨고 기존 카드는 유지된다

### 데이터와 오프라인

- [ ] `내보내기`가 JSON 파일을 내려받는다
- [ ] `데모 초기화`가 시드 데이터를 되돌린다
- [ ] 서버를 끄면 상단 상태가 `로컬에 저장됨`으로 바뀌고 기록은 계속된다
- [ ] 서버를 다시 켜면 `안전하게 동기화됨`으로 돌아온다
- [ ] 브라우저를 새로 고쳐도 기록이 남아 있다

### PWA

- [ ] 설정 탭에 설치 패널이 상황에 맞는 문구로 나타난다
- [ ] Chrome에서 `홈 화면에 추가`가 동작한다
- [ ] 설치한 앱을 오프라인으로 열어도 화면이 뜬다

### 프로필 (사용자)

- [ ] 첫 실행에 장난감 선택 다이얼로그가 뜨고 ESC로 닫히지 않는다
- [ ] 장난감을 고르면 카드 안에서 블루로 바뀌며 뛴다
- [ ] 이름 없이 시작하면 오류 문구가 뜬다
- [ ] 시작하면 홈 제목이 `{이름}의 리듬`, 캐릭터 캡션이 `{장난감 이름} · 기다리는 중`이 된다
- [ ] 설정 맨 위 프로필 카드를 누르면 장난감과 이름을 바꿀 수 있고, 이때는 닫기가 된다
- [ ] `데모 초기화`를 해도 이름과 장난감은 유지된다
- [ ] 새로 고침해도 온보딩이 다시 뜨지 않는다

### 루틴 카드

- [ ] 홈 상단 `나의 리듬` 아래 부제에 "아침 운동 · 밤 독서"처럼 반복 패턴이 나타난다 (기록 2일 이상 필요)
- [ ] 카드를 좌우로 넘기면 어제, 그제로 이동하고 점 표시가 따라온다
- [ ] 점을 누르면 해당 날짜 카드로 부드럽게 이동한다
- [ ] 기록을 시작하면 오늘 카드의 타임라인에 줄무늬 세그먼트가 늘어나고 `기록 중` 배지가 뜬다
- [ ] 기록이 없는 날은 회색 카드에 "이날은 기록이 없었어요"가 보인다
- [ ] 메모가 있는 날은 카드 하단에 마지막 메모가 인용된다

### 목표 추가 (홈)

- [ ] 홈 `목표` 섹션에 하루·한 주 목표가 각자 기간 배지로 보이고, 추가 버튼은 하나뿐이다
- [ ] `+ 목표 추가`(홈) 또는 `+ 추가`(나 탭)를 누르면 온보딩과 같은 모달이 뜬다 (칩 / 직접 입력 / 하루·한 주 / 프리셋)
- [ ] 추가하기 싫으면 × 또는 ESC로 닫히고 아무것도 저장되지 않는다 (버튼 선택 단계도 동일)
- [ ] 버튼이 4개 미만이면 저장 즉시 다음 버튼에 올라간다 (버튼 라벨에 `N번 버튼에 추가`)
- [ ] 버튼이 4개면 "어느 버튼에 올릴까요?"가 뜨고, 고른 자리의 활동은 목록에 남는다
- [ ] `지금은 목록에만 두기`를 고르면 버튼은 그대로고 흐름 탭 모든 활동에서 나중에 올릴 수 있다
- [ ] 기록 중에는 버튼 교체가 막히고 목록에만 추가된다

### 목표 단위

- [ ] 활동 추가 다이얼로그에서 `하루` / `한 주`를 고르면 목표 라벨과 기본값이 바뀐다
- [ ] 한 주 단위 활동은 홈 버튼에 `이번 주` 누적이, 하루 단위는 `오늘` 누적이 보인다
- [ ] 홈 `목표`에서 한 주 목표는 "하루 N분씩", 하루 목표는 "N분 남음"이 계산된다
- [ ] `나` 탭 목표 섹션에서 단위를 바꾸면 입력 상한이 720/5040으로 바뀐다

### 장난감 발화

- [ ] `나` → `지금 말 걸어보기`를 누르면 홈으로 이동하고 캐릭터가 말풍선과 목소리로 말한다
- [ ] `.env`에 키가 있으면 말풍선이 템플릿에서 모델 문장으로 바뀐다 (약 2–4초)
- [ ] 기록을 시작하면 "시작!", 끝내면 "끝!"을 높은 목소리로 외친다
- [ ] `목소리로 말하기`를 끄면 말풍선만 뜬다
- [ ] 조용한 시간을 1분으로 줄이고 기다리면 자동으로 말을 건다
- [ ] 버튼을 누르면 말풍선이 사라지고 캐릭터가 블루로 바뀐다
- [ ] 보드가 연결돼 있으면 말하는 동안 LED 4개가 함께 숨을 쉬고, 버튼을 누르면 멈춘다

### 하드웨어 (보드가 있을 때)

- [ ] `USB 연결` → 보드의 `BUTTON:1`이 기록을 시작한다
- [ ] 목표 진행률이 LED로 반영된다
- [ ] 연결을 해제한 뒤 즉시 다시 연결된다
